## 📌 Day 2 – Array Properties

### Topics Covered

- Shape
- Data Type (`dtype`)
- Number of Dimensions (`ndim`)

### Files

- `day2_shape.py`
- `day2_dtype.py`
- `day2_ndim.py`

### Concepts Learned

#### Shape (`shape`)

Returns the structure of an array.

Example:

```
(5,)
```

Means the array contains **5 elements in one dimension**.

---

#### Data Type (`dtype`)

Returns the data type of array elements.

Example

```
int64
float64
bool
```

---

#### Number of Dimensions (`ndim`)

Returns the number of dimensions present in an array.

Example

```
1
```

means it is a one-dimensional array.

### Skills Gained

- Understanding array properties
- Working with shape
- Checking data types
- Finding dimensions

## 📌 Day 4 – Array Slicing

### Topics Covered

- Basic Slicing
- Start Index
- Stop Index
- Step Value
- Reverse Slicing
- Negative Slicing

### File

- `day4_slicing.py`

### Concepts Learned

Array slicing is used to retrieve multiple elements from an array.

Syntax

```python
array[start:stop:step]
```

Examples

```python
arr[1:4]
arr[:5]
arr[2:]
arr[::2]
arr[::-1]
```

### Skills Gained

- Extracting elements
- Reverse arrays
- Step slicing
- Negative slicing
